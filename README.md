## ⌁ Quem somos

A **NPA Tecnologia** é um estúdio de engenharia de software de **São Paulo** que atende o **Brasil inteiro**. Construímos **sites de alta conversão, sistemas sob medida e automações com IA** — assumindo o ciclo completo: arquitetura, código, deploy e operação.

- ⚙️ **Generalistas por escolha** — web, back-end, integrações, dados e IA aplicada.
- 🚀 **Do commit ao deploy** — Next.js + Vercel, Postgres/Supabase, PHP/MySQL quando faz sentido.
- 🤖 **IA como ferramenta de negócio** — atendimento, qualificação e automações em WhatsApp.
- 🇧🇷 **LGPD-ready** — privacidade, consentimento e dados pessoais tratados desde o design.

## ⌁ Portfólio

> Provamos a engenharia com **código aberto e demos navegáveis**. Os projetos de clientes ficam em repositórios **privados** por confidencialidade (LGPD) — abaixo eles aparecem apenas de forma **agregada e anonimizada por segmento**.

### Repositórios públicos — código aberto

| Repositório | O que é | Tipo |
|---|---|---|
| 🧩 [**npa-next-template**](https://github.com/NPATecnologia/npa-next-template) | Template oficial NPA — Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui, LGPD-ready | Template · código |
| 🎛️ [**npa-landing-config-driven**](https://github.com/NPATecnologia/npa-landing-config-driven) | Landing **config-driven** multivertical — troca a vertical pelo arquivo de config | Template · código |
| 🛰️ [**npa-gmaps-photo-fetcher**](https://github.com/NPATecnologia/npa-gmaps-photo-fetcher) | Ferramenta de captura de fotos do Google Maps em alta resolução (Playwright) | Tooling · código |
| ⚖️ [**avn-legal-site**](https://github.com/NPATecnologia/avn-legal-site) | **DEMO fictício** de site de advocacia — dados 100% fabricados, sem cliente real | Demo público · código |
